# FILE_MAP.md

Repository layout. `docs/*Hierarchy.md` are generated by `npm run docs`; this
file is maintained by hand, so check it against the tree before trusting it.

```
/
├── AGENTS.md              Project conventions for agents
├── CLAUDE.md              How the owner wants updates reported
├── DEVELOPER_GUIDE.md     File structure and component logic
├── README.md              Running and setting up the project
├── firebase.json          Points the Firebase CLI at firestore.rules
├── firestore.rules        Access policy — must be published to take effect
├── generateDocs.cjs       Builds the docs/*Hierarchy.md files
├── populateQBs.js         Seeds/refreshes the players collection from the
│                          curated list in src/features/ranker/quarterbacks.js
├── index.html
├── jsconfig.json          The @/ path alias
├── package.json
├── postcss.config.js
├── tailwind.config.js
├── vercel.json            SPA rewrites
├── vite.config.js
├── vitest.config.js
├── docs/                  Schema reference and generated hierarchies
├── public/                Headshots, team logos, static assets
├── src/                   Application code (see AGENTS.md for the breakdown)
└── tests/                 Vitest suites
```

There is no `data/` directory; an earlier version of this file listed one.
